1. Modelagem
Cliente
Estrutura: Referenciado no pedido.
Motivo: O cliente pode fazer vários pedidos, então faz sentido manter as informações dele em um único lugar. Ao referenciar, evitamos duplicar dados e fica mais fácil gerenciar tudo centralizadamente.

Entregador
Estrutura: Referenciado no pedido.
Motivo: O entregador pode entregar vários pedidos, então, assim como no cliente, é melhor ter os dados dele de forma centralizada. Isso também facilita a manutenção caso precise atualizar alguma coisa sobre ele.

Pedido
Estrutura: Embutido, mas com referências para cliente e entregador.
Motivo: O pedido é o núcleo da aplicação, e nele ficam as informações mais importantes. Os produtos são específicos daquele pedido, então faz mais sentido embutir eles. Mas, para manter o relacionamento com cliente e entregador, referenciamos eles.

Produto
Estrutura: Embutido no pedido.
Motivo: Os produtos são exclusivos de cada pedido, então armazenar esses dados dentro do pedido facilita as consultas. Não precisa atualizar o produto separadamente, porque o preço e nome dele estão ligados diretamente ao pedido.


1.  Retorne todos os pedidos entregues por "Carlos Mendes".

db.pedidos.aggregate([
  {
    $lookup: {
      from: "clientes",
      localField: "cliente_id",
      foreignField: "_id",
      as: "cliente"
    }
  },
  { $unwind: "$cliente" },
  { $match: { "cliente.nome": "Carlos Mendes", status: "entregue" } }
])



2. Liste os nomes dos produtos e os totais de vendas (quantidade vendida) agrupados.

db.pedidos.aggregate([
  { $unwind: "$produtos" },
  {
    $group: {
      _id: "$produtos.nome",
      total_vendas: { $sum: 1 }
    }
  },
  { $project: { _id: 0, produto: "$_id", total_vendas: 1 } }
])

3.Encontre pedidos entregues perto da coordenada [-46.634, -23.551] com raio de 1 km.

db.pedidos.find({
  local: {
    $near: {
      $geometry: { type: "Point", coordinates: [-46.634, -23.551] },
      $maxDistance: 1000
    }
  }
})


4. Retorne todos os pedidos que contenham o item "Pizza Calabresa

db.pedidos.find({ "produtos.nome": "Pizza Calabresa" })

db.pedidos.find(
